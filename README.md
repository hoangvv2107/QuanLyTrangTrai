# Project Quản lý Trang trại
## Hướng dẫn cài đặt
1. Mở IDE (Eclipse, IntelliJ, NetBeans,...).
2. Tạo project Java mới.
3. Copy toàn bộ các file `.java` trong thư mục `src` vào thư mục `src` của project.
4. Thêm thư viện `mysql-connector-java.jar` vào Build Path / Libraries của project.
5. Cập nhật `USER` và `PASSWORD` trong file `DatabaseConnection.java` khớp với MySQL localhost của bạn.
6. Chạy class `QuanLyTrangTraiApp.java`.
